# Codex Command Extensions: data handling

Updated October 17, 2026.

The host reads registered command manifests and local launcher settings, and passes terminal input/output to the native Codex process or a feature process that you invoke. It stores registrations and launcher ownership under your Codex home. It does not operate a hosted service, add analytics, or store chat databases, pairing codes, or account credentials. Feature packages and the native Codex service have their own data handling.

Do not post private chats, credentials, pairing codes, or account identifiers in public issues. For support, use [GitHub issues](https://github.com/Cheaux/codex-command-extensions/issues) with synthetic or redacted examples. This document describes this community project; it does not replace the policies of Codex, ChatGPT, your model provider, or other feature packages.
